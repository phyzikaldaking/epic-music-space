# Release notes — 2026-08-26

## Operations hardening

- Added PostHog sink visibility to `/api/health`.
- Added worker liveness `/health` and readiness `/ready` endpoints.
- Added Redis-backed worker readiness and structured crash logs with stack traces.
- Added a production smoke command: `BASE_URL=... npm run smoke:production`.
- Added deployment and Prisma migration rollback procedures.

## Railway contract

- Web: healthcheck `/api/health`.
- Notifications worker: healthcheck `/health`.

- Readiness can be inspected at `/ready` on either worker.
